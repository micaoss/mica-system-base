## Description

Replace Debian's wpasupplicant and hostapd with packages built here from the same
source, with nl80211 only, libnl linked statically, OpenSSL for WPA2 and WPA3, and
no D-Bus, PC/SC, readline, P2P, WPS or mesh. Measured on 2.10: wpa_supplicant
1196 KiB and hostapd 844 KiB, loading only libraries the root already has, against
about 7.0 MB and five pinned packages today (mica:docs/plan/20260926-0930-mini-images-on-128-mb.md).

Acceptance:

- `debs/mica-wifi` and `debs/mica-wifi-ap` build for amd64 and arm64;
- neither binary loads libnl, libdbus, libpcsclite or libreadline;
- `wpa_supplicant@.service` and `hostapd@.service` keep the unit names and
  configuration paths micad drives today;
- the gates (`bun run check`) pass.
