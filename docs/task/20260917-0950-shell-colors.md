## Description

Login shells on the device show bash's built-in prompt (`-bash-5.2#`) and no
colors. mica-system ships `/etc/profile.d/mica-shell.sh`: for interactive bash on
a color-capable terminal it sets a colored `user@host:cwd` prompt (red for root),
loads `dircolors`, and aliases `ls`, `grep` and `diff` to `--color=auto`.

Acceptance:

- sourced by bash with a color TERM: colored PS1, `LS_COLORS` set, aliases defined;
- `TERM=dumb`, a non-interactive shell, or dash/busybox sh: no change, no error;
- mica-build keeps `/etc/profile` (fixed separately, uncommitted) and
  `/etc/profile.d/*.sh` owned by mica-system in the product root.
