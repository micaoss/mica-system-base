## Description

Stage 2 of the workspace migration to the release lock format
(`mica:docs/plan/20260914-2042-release-lock-offline-build.md`, specification
`mica:docs/design/release-lock.md`), dispatched by the coordinator on the user's
order:

- read the build environment from `locks/mica-build-env.lock` and its pin,
  every image included (no Docker Hub reference);
- move every third-party pin into `locks/upstream.lock` (`source` rows), with
  the selections in `packages.tsv`;
- publish exactly `mica-system-base.lock` and `SHA256SUMS`, with no transition;
- prove the readers and the writer with the spec's vectors.

Done on mica-build-env 20260915-0138, with the history squashed to one root
commit and the earlier releases, tags, workflow runs, package versions and
records removed on the user's instruction; the first release in this format
follows from that root commit.
